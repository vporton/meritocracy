# Command validation rules

All commands accept an opaque caller-supplied idempotency key except immutable
governance finalization (whose key is its period/version) and migration (whose key is
the source row hash plus transform version). Every command begins by returning the
stored response for the same key and semantically identical request. Invalid input is
a typed result, never a trap. `Corruption` pauses the affected entity/queue and emits
an operational alert; a trap is reserved solely for an unreachable programmer-bug
assertion.

|Command / update operation|1. Input validation|2. Authentication validation|3. Authorization validation|4. Referenced-record validation|5. State-transition validation|6. Uniqueness validation|7. Aggregate validation|8. Commit operation|9. Typed failure result|
|---|---|---|---|---|---|---|---|---|---|
|Claim/link account identity|Bounded normalized proof/commitment; request key|Caller principal or verified off-chain proof|Owner may link only self; identity worker may attest|Account (if linking), provider/policy exist|Account is claimable/active; attestation is valid|Identity map and account key unused or same idempotent owner|Active commitment cap; profile privacy constraints|Identity map + Account + attestation ref + audit, then optional projection|User: `ValidationError`; conflict: `Conflict(identity_claimed)`; auth: `AuthenticationError`/`AuthorizationError`; missing: `NotFound`; corrupt: `Corruption`|
|Change profile/consent|Bounded allow-listed public fields, formats, expected version|Authenticated principal|Caller owns Account|Account exists; policy version exists|Account active; deleted account cannot publish|One profile/account and optional policy-normalized public handle|Document byte/count cap; fixed-point share not caller-controlled|Account version + public profile/index + audit atomically|`ValidationError`, `AuthorizationError`, `NotFound`, `Conflict(version_mismatch)`, `StateConflict`, `Corruption`|
|Tombstone account|Expected version, deletion reason; no private payload|Authenticated principal|Owner, or narrowly defined governance procedure|Account exists; active obligations/appeals loaded|Only active/restricted → deleted if policy permits|Deletion key replay-safe|No removal of financial/governance facts; profile index removed|Account tombstone + public projection removal + erasure Work item + audit|`AuthorizationError`, `NotFound`, `PreconditionFailed(obligations_open)`, `Conflict`, `Corruption`|
|Issue/revoke verification attestation|Provider-signed bounded attestation/ref; expiry and schema version|Authorized identity/KYC worker or governance|Worker limited to provider/kind; governance revokes|Account and provider/policy exist|`proposed → verified/rejected`; verified → revoked/expired|Attestation ID and active-kind policy key|Bounded active attestations; update Account eligibility version|Attestation + Account eligibility/active-run guard + audit|`ValidationError`, `AuthenticationError`, `AuthorizationError`, `NotFound`, `StateConflict`, `Conflict`, `Corruption`|
|Request assessment|Request key, expected Account version, bounded request/ref|Authenticated owner|Owner only|Account, active policy and required attestations exist|`not_started/rejected/expired → requested`; no active run/retry block|Run ID and account/policy active-run key|Eligibility and Work-item queue limit|Account claim + run + Work item/index + audit; call worker only afterwards|`PreconditionFailed(ineligible)`, `Conflict(assessment_active/version_mismatch)`, plus standard validation/auth/not-found/corruption|
|Submit/accept assessment result|Worker result schema, bounded hashes/sources, run/version|Authorized worker for submit; governance/core for accept|Worker cannot accept own arbitrary result|Run, Account, worker attestation, policy exist|`requested → executing → proposed → accepted/rejected`; terminal immutable|Run ID; source ordinals/URL hashes unique|Fixed-point score/share and Account current-run/version match|Run document + Account result/share + profile projection/index + audit atomically|`ValidationError`, `AuthorizationError`, `NotFound`, `StateConflict`, `Conflict`, `Corruption`|
|Submit vote|Target, allowed type, bounded message/commitment, canonical period, request key|Authenticated principal|Eligible voter only|Voter, target, open period, policy exist|Period open; target != voter|Composite `(period,target,voter)` key|Target/period aggregate increments exactly once|Vote key/record + aggregates + audit atomically|`ValidationError`, `AuthorizationError`, `NotFound`, `PreconditionFailed(voter_ineligible)`, `Conflict(vote_exists)`, `StateConflict`, `Corruption`|
|Finalize governance outcome / apply hold|Period/version, deterministic outcome evidence|Governance principal|Governance finalizer role|Period, policy, votes/aggregate, target Accounts exist|`closing → finalized`; hold transition allowed|Finalization key/policy version unique|Recompute/verify aggregate against vote keys before decision; compensation policy applies once|Outcome + Account hold(s) + compensation intent(s) + audit atomically|`AuthorizationError`, `NotFound`, `Conflict(finalized_or_version)`, `StateConflict`, `Corruption`|
|Set active treasury policy|Bounded policy values, assets, limits, fixed-point config, expected version|Governance principal|Governance policy role|Singleton/policy draft exists|Draft → approved → active; supersede prior only once|Policy version and active-pointer compare-and-set|Validate supported asset count, limits, and reserve compatibility|Immutable policy version + singleton pointer + audit atomically|`ValidationError`, `AuthorizationError`, `NotFound`, `Conflict(version)`, `StateConflict`, `Corruption`|
|Configure/reconcile reserve|Asset key, integer amount/observation, expected reserve version|Governance or reconciler principal|Role limited to assigned asset|Policy and Reserve exist (or governed create)|Configured → active/paused/retired only by policy|Asset key unique|No negative values; ledger observation/reconciliation rule passes|Reserve + reconciliation Work item/status + audit atomically|`ValidationError`, `AuthorizationError`, `NotFound`, `Conflict(version)`, `PreconditionFailed(reconciliation_required)`, `StateConflict`, `Corruption`|
|Allocate payment obligation|Period/account/asset/destination commitment, integer amounts, policy/request key|Governance allocation job/core|Governed allocator only|Account eligible, policy and active Reserve exist|Account not held; obligation starts `created`|Allocation key, obligation ID, memo all unused or idempotent same request|Available reserve ≥ amount; non-negative integer arithmetic|Reserve reservation + obligation/key/status indexes + ZenDB doc + Work item + audit atomically|`ValidationError`, `AuthorizationError`, `NotFound`, `PreconditionFailed(account_held)`, `Conflict(obligation_exists)`, `Conflict(insufficient_reserve)`, `Corruption`|
|Claim/settle/reconcile obligation|Expected obligation version/lease, receipt/ref or bounded failure code|Executor/reconciler principal|Executor assigned asset; reconciler scope|Obligation, reserve/policy and referenced receipt status exist|Only allowed lifecycle edges; settled needs unique valid receipt; ambiguity → reconcile-required|Lease/version and receipt/memo unique|Attempt cap; settlement/reserve accounting balances|Claim is atomic; external ledger call only after claim; later receipt/status/index/doc/audit commit is atomic|`AuthorizationError`, `NotFound`, `Conflict(lease_or_receipt)`, `StateConflict`, `PreconditionFailed(reconciliation_required)`, `Corruption`|
|Claim/complete core Work item|Bounded kind/payload reference, expected lease/version|Authorized worker|Worker role/kind scope|Work item and target entity exist|Pending/retryable → claimed → submitted/completed/failed/reconcile-required; expired lease may re-claim|Work ID/idempotency key unique|Queue/index consistency, per-call limit and lease timing|Work state/index + target transition when applicable + audit atomically|`ValidationError`, `AuthorizationError`, `NotFound`, `Conflict(lease/version)`, `StateConflict`, `Corruption`|
|Read cursor-page projection/history|Signed/versioned cursor, declared filter/sort, bounded limit|Caller principal when data restricted|Owner/role scope; public collection only public fields|Cursor target/index exists|N/A|Cursor binds filters/sort; no command replay concern|Declared index only; deterministic tie-breaker|Read-only; decoder verifies record/index coherence|`ValidationError(cursor_or_limit)`, `AuthenticationError`, `AuthorizationError`, `NotFound`, `Corruption`|
|Import migration batch|Snapshot ID, transform version, bounded cursor/limit, source-key hash; no raw secret/PII|Governance migration principal|Migration role only|Validated referenced target claims/policies exist|Receipt `received → imported/rejected → reconciled` only|Receipt key and target uniqueness maps|Per-row identity, transition, index and financial reconciliation checks; batch never scans unbounded data|For each row: target mutation + immutable receipt + audit; rejected rows are recorded, not trapped|`ValidationError`, `AuthorizationError`, `NotFound`, `Conflict(receipt_or_target)`, `PreconditionFailed(reconciliation_required)`, `Corruption`|

## Failure classification

|Class|Meaning|Examples|Handling|
|---|---|---|---|
|User error|Malformed or policy-disallowed input|bad address, oversize document, self-vote|`ValidationError`; caller can correct it|
|Conflict|A valid request races or repeats a different command|duplicate identity/vote, version or lease mismatch|`Conflict`; return prior success for exact idempotent replay|
|Authorization failure|Caller has no required authority|other-account profile write, public distribution trigger|`AuthenticationError` or `AuthorizationError`|
|Missing data|Allowed reference is absent|unknown account/run/reserve|`NotFound`|
|Internal corruption|Persisted state/index/accounting violates this contract|negative reserve, duplicate canonical key, bad decoder|`Corruption`; quarantine/pause and audit/alert|
|Programmer error|An unreachable violated internal assertion|impossible exhaustive-variant branch|Trap only here; never expose it as normal command control flow|
