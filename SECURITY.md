# Security Policy

## Supported Versions

Versions of your project are supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| stable  | :white_check_mark: |
| main    | :x:                |
| devel   | :x:                |

## Reporting a Vulnerability

Report vulnerabilities using Security tab at GitHub. Security reports should not be disclosed to any third parties.
