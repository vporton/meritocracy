# Service interfaces

## Shared service contract

Services accept domain commands rather than Candid records and return `Result<T, DomainError>`. `DomainError` maps to the taxonomy in `invariant-mapping.md`: `ValidationError`, `AuthenticationError`, `AuthorizationError`, `NotFound`, `PreconditionFailed`, `Conflict`, `StateConflict`, `Corruption`, or `InternalError`. Mutating commands include a caller context, idempotency key, expected version where Candid requires one, and correlation ID.

An atomic transaction below is one no-`await` core update containing the canonical mutation, secondary indexes, idempotency receipt, redacted audit event, and either the ZenDB projection or a durable projection-outbox event. External calls occur only after a durable intent/lease and are reconciled in a later command.

|Service|Commands / typed results|Queries|Dependencies|Invariants enforced|Transaction boundary and workflow events|
|---|---|---|---|---|---|
|`AccountService`|`UpdateMyProfile` → `PublicProfile`; `TombstoneMyAccount` → `Empty`; `SetAccountRole` → `GovernanceReceipt`|`GetMyAccount`; `GetPublicProfile`; `ListLeaderboard`|AccountStore, ProfileRepository, IdempotencyReceiptStore, AuditLog, AuthorizationPolicy, policy reader, projection coordinator|consented/public allow-list only; no PII; expected version; one profile/account; tombstoned account rejects further commands; role changes governance-only|profile/account/index/audit/receipt together. Emits `ProfileProjectionRequested`, `AccountTombstoned`, `PrivateErasureRequested` (the latter only after tombstone commit).
|`AttestationService`|`ProposeAttestation`, `RevokeAttestation` → `AttestationDecision`|authorized account/role-scoped attestation view only|AccountStore, AttestationStore, AuditLog, receipts, AuthorizationPolicy, policy reader|allow-listed worker/provider/schema; unique worker event and subject commitment; finite attestation states; no credential/PII|attestation, active index, account eligibility/version, audit and receipt together. Emits `EligibilityChanged` and possibly `AssessmentBlocked`.
|`AssessmentService`|`RequestAssessment`, `RetryAssessment` → `AssessmentSummary`; `ClaimEvaluationWork` → `WorkDescriptor`; `SubmitAssessmentProposal` → acceptance result|`GetMyAssessment`; `ListMyAssessments`; governed work/status pages|AccountStore, AttestationStore, AssessmentRun repository/store, WorkStore, receipts, audit, authorization, policy, projection coordinator|eligible active account; exactly one active run; deterministic run/work ID; lease/version; schema/worker/source caps; accepted result updates account once|request commits Account + Run + active index + Work + audit + receipt, then emits `EvaluationRequested`; claim commits lease then external work; acceptance commits Run + Account + indexes + audit + receipt and emits `AssessmentAccepted`/`AssessmentRejected`.
|`GovernanceService`|`ActivatePolicy`, `FinalizeVotePeriod`, `SubmitVote`, `CreatePaymentObligation`, `RunMaintenanceBatch` → receipt/vote receipt|`GetVotePeriod`; `ListVotePeriods`; public status/reserve aggregate inputs|PolicyStore, VoteStore, PeriodStore, AccountStore, ReserveStore, ObligationStore, WorkStore, audit, receipts, AuthorizationPolicy, calculation functions|single active policy; voter eligibility/non-self/one vote per key; period state/version; pinned period policy; reserve conservation; deterministic allocation key|each command commits its full canonical group and audit/receipt. Emits `VoteSubmitted`, `PeriodFinalized`, `HoldChanged`, `PaymentAuthorized`, `MaintenanceScheduled`; payment execution is never direct.
|`PaymentService`|`ClaimExecution` → `ExecutionInstruction`; `SubmitSettlementObservation` → obligation result; `ProposeOracleObservation` → version receipt|`ListMyObligations`; restricted reconciliation view|ObligationStore, PaymentObligationRepository, ReserveStore, WorkStore, PolicyStore, audit, receipts, AuthorizationPolicy, projection coordinator|executor cannot create/change entitlement/amount; lease/version; finite lifecycle; settled requires unique receipt; ambiguity never auto-resends; integer reserve accounting|claim commits `executing` lease/audit before await and emits `PaymentExecutionClaimed`; observation commits one reconciled state + receipt/reserve/work/audit and emits `PaymentSettled`, `PaymentRetryable`, or `PaymentReconciliationRequired`.
|`QueryService`|none|all public/owner/restricted queries; certified status/period/reserve models|read ports, AuthorizationPolicy, cursor validator, certification service|visibility/redaction, bounded filters/pages, stable ordering; certification derives from canonical public facts|read-only; emits no workflow event. It never treats a missing/stale ZenDB document as missing canonical state—may request rebuild.
|`MigrationService`|`ImportMigrationBatch` → receipt; `RebuildProjectionBatch` → receipt|migration progress/quarantine report for governance|MigrationReceiptStore, all canonical stores, ZenDB repositories, audit, AuthorizationPolicy, versioned transforms|migration principal only; bounded cursor; source hash + transform version idempotency; no secrets/PII/raw logs; no silent coercion; ambiguous financial values quarantine|per-row canonical write + receipt + audit; cursor advances only after all row outcomes persist. Emits `MigrationRowImported`, `MigrationRowQuarantined`, `ProjectionRebuildRequested`.
|`WorkService`|`ClaimWork`, `CompleteWork`, `FailOrReconcileWork` → work receipt|restricted work pages|WorkStore, audit, receipts, AuthorizationPolicy, clock|kind-specific role, lease ownership/expiry/version, finite state machine, bounded payload reference|lease/target transition/audit/receipt together. Emits `WorkClaimed`, `WorkCompleted`, `WorkRetryScheduled`; it cannot mutate a domain aggregate except through the owning service.

`CertificationService` is a read-model collaborator, not a command service: it builds witnesses from canonical public status, vote period and reserve aggregate after `QueryService` has selected the permitted data. `AuthorizationPolicy` is a dependency of every service that exposes or changes protected facts; repositories receive a scope only for mechanically limiting a query, never an actor to adjudicate.
