# Invariant and constraint mapping

This is the implementation contract for the ICP cutover. `Stable` means canonical
`meritocracy_core` stable state; `ZenDB` means a bounded projection/history document;
`off-chain` means the designated identity, KYC, worker, or secret service.  An update
that changes canonical state and a ZenDB projection writes both before returning. A
redacted audit event is appended in that same update. `await` means an inter-canister
or external await: no mutable invariant may be held across it.

## Target error taxonomy

`ValidationError` is a user-correctable malformed input. `AuthenticationError` and
`AuthorizationError` are access failures. `NotFound` is an absent allowed reference.
`PreconditionFailed` is a valid request that cannot currently proceed.
`Conflict` covers duplicate idempotency keys, uniqueness keys, leases, and versions.
`StateConflict` is an invalid lifecycle transition. `Corruption` means decoded state,
an index, or accounting data violates an invariant; it is surfaced as a controlled
maintenance condition. `InternalError` is an unexpected infrastructure failure.
Only programmer-bug assertions may trap; all other cases return typed results.
